About NST Studio

Exploring the relationship between photographs and artistic styles.

What is neural style transfer?

Neural style transfer creates an image by combining the structure of a photograph with visual characteristics from an artwork, such as colours, textures and patterns.

How this project works

NST Studio uses a pretrained VGG19 neural network to extract content and style features. The network stays fixed while the generated image's pixels are adjusted repeatedly to balance content, style and smoothness.

Flask connects the webpage to the Python image-generation pipeline. MySQL stores completed generation records, while image files remain in local storage.

From final-year project to web application

This application extends a Jupyter Notebook project investigating neural style transfer. The website adds image uploads, adjustable settings, downloadable results and database-backed generation history.

Understanding the results

Stronger style influence can introduce more artistic texture while changing the original structure. Additional iterations increase processing time but do not guarantee a more visually appealing result.

Current limitations

  • CPU processing can take time.
  • Images are resized for manageable processing.
  • Fine details may soften or become distorted.
  • Visual quality depends on the images and settings.
  • This local version has shared history and does not separate records into individual user accounts.
